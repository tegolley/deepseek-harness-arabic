# دعم العربية RTL في DeepSeek Harness

## للمحترفين

من جذر هذه النسخة، شغّل العرض المعزول بعد تثبيت Git وDocker مع Compose:

```bash
bash docker/build-arabic-demo.sh
docker compose -f compose.arabic-demo.yml up -d
docker compose -f compose.arabic-demo.yml logs --tail=30 dsh-arabic-demo
```

## للمبتدئين

1. ثبّت Git وDocker مع Compose ثم نزّل [النسخة العربية RTL](https://github.com/tegolley/deepseek-harness-rtl-arabic).
2. افتح نافذة أوامر داخل مجلد النسخة ونفّذ الأوامر السابقة بالترتيب.
3. انسخ رابط `dsh web:` من السجل وافتحه على الجهاز نفسه. احتفظ برمز الدخول لنفسك.
4. جرّب نصاً فيه عربية وإنجليزية وأرقام، مثل `Model X سعره 123 ريال والإصدار Pro 2`.
5. أضف إعداد نموذج داخل الواجهة فقط إذا أردت رداً فعلياً. [الشرح الكامل خطوة بخطوة](docs/arabic-support/INSTALL.ar.md).

## عن هذه النسخة

هذه نسخة مشتقة من [DeepSeek Harness الرسمي](https://github.com/deepseek-ai/deepseek-harness) تضيف عرضاً مناسباً للعربية في واجهة الويب. التعديل محصور في إضافة مستقلة داخل `packages/client/ui-arabic-support`، لتبقى متابعة تحديثات المشروع الأصلي واضحة وقابلة للمراجعة.

## ماذا تشمل النسخة؟

- اتجاه الكتابة في مربع المحادثة ورسائل المستخدم والردود.
- الفقرات والقوائم والعناوين والاقتباسات التي تجمع العربية مع الأرقام أو الأحرف اللاتينية.
- كتل الشيفرة وبطاقات الأسئلة ومراجعة الخطط.
- عرض الأسعار المكتوبة بالعربية عند تفسير علامتي عملة على أنها صيغة رياضية.
- بقاء النص الإنجليزي وحده باتجاهه الطبيعي.

الإضافة تعالج طريقة العرض في المتصفح. لا تترجم عناصر الواجهة، ولا تغير طلبات النموذج أو إعدادات الحساب.

## جرّبها محلياً في حاوية مستقلة

تحتاج إلى Git وDocker مع إضافة Compose، ومساحة بناء إضافية فوق حجم الصورة الذي قارب `5.5GB` في التجربة. من جذر المستودع:

```bash
bash docker/build-arabic-demo.sh
docker compose -f compose.arabic-demo.yml up -d
docker compose -f compose.arabic-demo.yml logs --tail=30 dsh-arabic-demo
```

افتح رابط البدء الذي يظهر في السجل على **نفس الجهاز**. يبدأ العرض على المنفذ `49251` ويرتبط بـ `127.0.0.1` فقط. رابط البدء يحتوي رمز دخول، فلا تنشره. لا يلزم مفتاح نموذج للتأكد من ظهور الواجهة، بينما تحتاج إلى إعداد نموذج إذا أردت إجراء محادثة.

لإيقاف العرض:

```bash
docker compose -f compose.arabic-demo.yml down
```

يحفظ Compose بيانات العرض في وحدة تخزين مستقلة. [خطوات التثبيت والتحقق كاملة](docs/arabic-support/INSTALL.ar.md).

## التثبيت من المصدر

إذا أردت تشغيل النسخة دون Docker، اتبع [خطوات التثبيت من المصدر](docs/arabic-support/INSTALL.ar.md#التثبيت-من-المصدر). التعديل مضمّن في حزمة الويب، فلا تحتاج إلى نسخ ملفات من جهاز آخر أو تثبيت إضافة خاصة.

## التحديثات من المشروع الأصلي

يفحص سير العمل `upstream-sync.yml` تحديثات الفرع الرسمي أسبوعياً. عند إمكان الدمج، يفتح طلب دمج للمراجعة ويشغّل اختبارات النسخة العربية. التعارضات والاختبارات الفاشلة تحتاج مراجعة قبل الدمج. [تفاصيل المتابعة](ARABIC_SUPPORT.md#follow-upstream).
